    Biztory Copy & Paste Guide

    Why multi-line descriptions split rows in Biztory & the solutions

    Why Do Items Break Into Multiple Rows in Biztory?

    When you copy a table from Excel or web apps and paste into Biztory's invoice/quote grid, Biztory uses a simple script that treats every single Enter / Newline (\n) as the start of a brand new item row. Even if the text is wrapped in quotes, Biztory ignores them and splits your remarks (#OFFER, maker name, specs) into separate phantom lines, corrupting prices and quantities.

    Solution 1: Use "Biztory (Single-Line //)" (Recommended)

    Select Biztory (Single-Line //) in the Format dropdown before clicking Copy for Cloud Accounting. This automatically converts all newlines inside descriptions into clean inline separators ( // ):

    LED T8 Tube Light 2FT/20W // #OFFER: 2FT/ 20W /6500K WHITE
    DEWALT DW810B // #OFFER: Rated power: 710W | No-load speed: 12000 rpm

    ✓ 100% Guaranteed: Each item pastes as exactly 1 row into Biztory. Qty, Unit, and Price never shift!

    Solution 2: Use "Biztory (Soft Line Break)"

    Replaces standard newlines with Unicode line breaks (\u2028). In browser text inputs, this visually breaks onto multiple lines without triggering Biztory's row-splitting code!

    Solution 3: 1-Click "Copy Desc" on Individual Rows

    Need an individual item in Biztory to have the exact multi-line bullet points (like technical specs)?

    Click the small 📋 Copy Desc button directly under that item's description in our table. Then click into Biztory's description box and press Ctrl + V!

    Pro-Tip inside Biztory: When manually typing into Biztory's description field, press Shift + Enter or Alt + Enter to create a new line without submitting the line item.
